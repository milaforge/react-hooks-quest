# React Hooks Quest

Learn React Hooks through short interactive missions.

React Hooks Quest is a small educational game inspired by Rustlings. Instead of following tutorials, players complete bite-sized challenges that test their understanding of React concepts.

The game focuses on reasoning and mental models rather than writing large amounts of code.

Progress is stored locally using `localStorage`. No account is required.
