# React Hooks Quest

Understand React Hooks by solving short interactive coding challenges.

This is a small educational game inspired by Rustlings. Instead of reading tutorials, you complete bite-sized missions that teach one React Hook at a time.

Progress is stored locally using localStorage. No account is required.

--- 

## Features

- 20–30 short missions
- XP progression
- Local progress saving
- Hint system
- Responsive UI
- Zero backend

---

## Hooks Covered

- useState
- useEffect
- useContext
- useRef
- useReducer
- useMemo
- useCallback

---

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
