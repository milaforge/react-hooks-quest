# Software Requirements Specification

## 1. Purpose

React Hooks Quest is an educational web application that teaches React Hooks through interactive coding exercises.

The project focuses on practical understanding rather than passive reading.

---

# 2. Goals

- Learn by doing
- Small missions
- Immediate feedback
- Local-first
- No login
- Fast (<1 second between actions)

---

# 3. Target Users

- Learning React 
- Deepening your understanding of React 

---

# 4. Functional Requirements

## FR-1

The user shall start a new game.

---

## FR-2

The user shall complete missions.

---

## FR-3

Each completed mission awards XP.

---

## FR-4

XP unlocks new chapters.

---

## FR-5

Progress shall persist using localStorage.

---

## FR-6

Completed missions shall not award XP twice.

---

## FR-7

The user can reset progress.

---

## FR-8

Hints may be viewed.

Viewing a hint does not block completion.

---

# 5. Non-functional Requirements

- Mobile friendly
- Accessible
- Offline capable
- No backend
- No authentication
- Load in under 2 seconds

---

# 6. Scope

Included

- React Hooks
- XP
- Progress
- Hints

Excluded

- Multiplayer
- Backend
- Accounts
- Leaderboards
- AI

---

# 7. Success Criteria

A player can:

- Complete every mission
- Understand every hook
- Resume later
- Finish within about one hour
